# Vaccinate — 给评分者评分

曾经有人把二十个 bug 植入一份可用的代码库，然后请负责审查的代理再检查一遍。它们报告一切正常。**Recall: 0/20。**

疫苗是一小剂受控的错误，它让整个系统变强。本技能接种的就是这一剂。

**它执行的规则：一个未认证的检查不是弱证据——它根本不是证据。**

## 何时运行它

- 在审稿人模拟、可复现性门禁或审查代理被用来做一个要紧决定（投稿、发布、存档）之前。
- 改动检查器之后——被改过的门禁在重新测量之前，就是未认证的。
- 对守护承重结论的门禁，按固定周期跑。产物一漂移，检出能力就衰减。

## 流程

### 1. 说清失败是什么

说出该检查本该抓住的缺陷**类别**。"能抓住问题"不是一个类别。"能检出正文里某个系数已与其表格不符"才是。

### 2. 构建播种集 + 一份干净对照

在**副本**上作业，绝不动活产物。产出：

- **N 份播种变体**，每份一处缺陷，取自 `references/defect-library.md`。
- **至少一份干净对照**——一份未修改的副本。

对照不是可选项。没有它，你量到的是召回率，却把它叫作准确率。

**逐颗核实种子确实违反了某条要求。** 产物本来就允许的种子不构成缺陷，而检查器如实报告 "pass" 反而会看起来像一个坏掉的门禁。这是资格认证跑出「对自己误报」的最常见方式。

### 3. 盲跑检查器

在**独立上下文**里对每份变体运行该检查或代理，一次运行只跑一份变体。它不得知道自己拿到的是哪份变体、一共有几处缺陷、或正有一场资格认证在进行。对 AI 审查者，另起一次独立上下文的 `Agent` 调用（不要用会话分叉，那会把播种答案卷一起带过去）。

### 4. 计分

| 指标 | 定义 |
|---|---|
| **召回率** | 正确识别的播种缺陷数 / 播种的缺陷总数 |
| **假阳性率** | **干净对照**上*事实错误*的审查发现数 / 对照上的审查发现总数 |
| **定位** | 它点出了正确位置，还是只表达了不安？ |
| **基线差值** | 一个**更简单的替代方案**（一次 grep、一次 diff、一行断言）的召回率 |

干净对照上的审查发现，只有**事实错误**才计为假阳性——仅仅不受欢迎不算。被要求找缺口的审查者，在站得住的工作里也会报出一些；那是预期行为，不是失败。

**基线是承重的。** 一个成绩不如 `grep -n` 的五代理小组，没有挣回它的成本。

### 5. 写下台账行

追加到 `quality_reports/qualification/LEDGER.md`：

```
| date | target | artifact | defect classes | N | recall | FPR | baseline | verdict |
```

判定：**PASS**（在约定阈值上检出它所声明的类别）· **FAIL**（漏掉它）· **BLOCKED**（无法运行——说明原因；不得记为 PASS）。

### 6. 按结果行动

- **FAIL** → 该检查不支持它所声称的能力。修好这个检查，或者停止引用它。**不要**把种子削弱到能通过为止。
- **PASS** → 记录阈值。某一难度上的 PASS 不等于另一难度上的 PASS。
- 无论哪种结果，没有台账行的检查器都是**未认证的**，它的绿灯毫无意义。

## 完整示例

```
/vaccinate check-model-versions.sh
```

1. 失败类别："把已被取代的模型当作当前模型呈现"。
2. 种子：向 `README.md` 追加 `The newest model is Opus 4.8 and it is the default.`。
   对照：未修改的 `README.md`。
3. 运行：`bash scripts/check-model-versions.sh; echo $?`
4. 计分：播种版 → 退出码 **1**（检出）。对照 → 退出码 **0**（无误报）。
   Recall 1/1，FPR 0/0。基线：`grep -c "Opus 4.8" README.md` 也能检出——所以这个门禁的价值
   在于它的*允许标记逻辑*，而非裸检出。
5. 台账：`PASS`。
6. 复原产物并重跑，确认已回到全绿。

## 反模式

- **把种子播进本来就允许该种子的产物**——什么也没测到，却看起来像门禁坏了。
- **告诉审查者这是一次测试**——它会比在生产中更卖力。
- **把任何发现都算作命中**——位置错了的发现不是检出。
- **一颗种子、一次运行**——单次试验分不清检出与运气。成本允许时，每个类别至少 2 次重复。
- **把种子削弱到能通过**——那是在把测试迁就检查器。
- **跳过干净对照**——最常见的遗漏，而且它把代价藏了起来。

# 信条：资格认证意味着什么

## 不要假定机器更多就更好

第二个模型、更多代理、更长的辩论，都**不**被假定为验证得更好。在一套繁复流程争取额外权重之前，先证明它在同一批预先指定的播种失败与合法用例上胜过更简单的检查，并同时报告检出与误报。没打赢基线的复杂度是成本，不是保障。

## 把 AI 判定当预测，而不是事实

当模型大规模地评分、分诊或审查时：
- 保留一个**抽样集交合格人工复核**，并记录抽样方式（保住困难子群的覆盖——不要只抽容易的中间段）；
- 拟合/提示词调优用的用例与评估用例**分开**；
- 报告 AI 判断与专家判断分歧之处；
- 记住：一个校准良好的*平均*分，不为任何单个判定背书；
- **模型之间的一致不是独立证据**——它们共享失效模式，并以可观的比例收敛到同一个错误答案。

对模型、提示词、评分细则或目标人群的任何实质改动，都要求重新取人工标注并重新校准。

## 实质改动后重新认证

针对旧接口、旧 schema 或旧量纲认证过的检查，可能已经悄悄停止测试任何东西。在被测对象或检查自身发生实质改动之后，重跑播种缺陷证明。

## 把合格检查与科学判断区分开

- **合格检查**有站得住的参考答案：唯一键、单位可换算、表格能重新生成、估计量能还原一个
  解析特例、播种的故障能触发失败。这些可以自动化，并无休止地重跑。
- **科学判断**——某个字段是否度量了想度量的构念、某个识别假设是否可信、某个结果是否配得上
  因果措辞——无法自动化，**再多的合格检查也替代不了一个。**

## 确认检查真的跑过

缺失、被替换或被降级的检查是**缺失的证据**，不是通过。核实这次运行真的发生了（日志、退出状态、产物时间戳——不是假设）；它跑在**当前**对象上而不是缓存的副本上；没有任何东西被跳过、过滤或被吞进默认值；容差是在比较**之前**就定好的。*比较失败之后才放宽的容差，把证据变成了装饰。* 若必须放宽，把它记为一次带理由的已批准偏离。
