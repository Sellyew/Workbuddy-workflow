# 缺陷库——该植入什么

植入一个*逼真的*缺陷才是难的部分。一个笔误不算一次测试。下面这些取自
在实证工作中确实从审阅里活下来的缺陷类别。

每条：改什么，以及**一个称职的检查器该说什么**。

---

## 实证分析代码（R / Stata / Python）

| # | 植入口 | 预期检出 |
|---|---|---|
| A1 | 在组装处理效应时翻转一个符号 | 估计值变号；对账检查或固定样例检查失败 |
| A2 | 滞后窗口差一位（首个滞后用 `t-1` 而非 `t`） | 拟合序列整体移一个时期；首滞后系数变动 |
| A3 | 在错误的层级上聚类（用个体而非处理分配层） | 标准误明显缩小；聚类断言失败 |
| A4 | 在合并时静默丢行（本该用 `left` 却用了 `inner`） | N 下降；一条合并后计数断言失败 |
| A5 | 删掉 `set.seed()` / `set seed` | 结果不再逐位复现 |
| A6 | 重排因子水平，使参照类别改变 | 系数重新定基；对照标签与正文不再匹配 |
| A7 | 某个设定里忽略调查/抽样权重 | 点估计偏离加权表 |
| A8 | 把某个比较的容差放宽 10 倍 | 一个原本失败的格子现在通过了——**检查应当标记容差变更本身** |
| A9 | 用一个硬编码字面量替换算出来的常量 | 数值不再跟随其输入；血缘检查失败 |
| A10 | 让某个变换函数原样返回输入 | 下游与上游完全相同；实质性检查失败 |

## 稿件

| # | 植入口 | 预期检出 |
|---|---|---|
| M1 | 改动正文里的一个系数，使它不再与表一致 | 该断言上的数值溯源检查失败 |
| M2 | 为一篇真实论文并不成立的断言引用它 | 引文保真 / CoVe 标记出无支持的归属 |
| M3 | 编造一条看起来像样的参考文献 | 编造引文检查失败 |
| M4 | 把加了限定的措辞升级为确定式（"suggests" → "demonstrates"） | 报告语言的升级被标记 |
| M5 | 把一个逐点成立的结果说成一致成立 | 过度断言：标题句超出了所证内容 |
| M6 | 在摘要里改动 N，但表里不改 | 跨产物一致性失败 |
| M7 | 在定理陈述里删掉一条必要假设，却保留证明 | 证明缺口：结论不再成立 |
| M8 | 在测量模型的写作里，把某条假设的条件形式换成无条件形式 | 领域审阅标记出假设错配 |

## 选 N

- **冒烟资格：** 3 个植入 + 1 个对照。足以抓住一个坏掉的检查器。
- **标准：** 跨 ≥3 个类别 6–10 个植入 + 1 个对照，每个重复 2 次。
- **在作出投稿级断言之前：** 该检查声称覆盖的每一个类别都要覆盖，≥2 次重复，
  外加每个类别一个干净对照。

报告你**没有**植入什么。一次只覆盖三个类别的资格认许，只能支撑关于三个类别的断言。
