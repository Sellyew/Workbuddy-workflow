# 探索快速通道

**实验性工作走这条轻量流程。**质量阈值为 60/100，生产工作为 80；无需制定计划。

## 步骤

1. **研究价值检查**：先问这项工作能否改进项目。不能，就不要做。
2. **建目录**：运行 `mkdir -p explorations/[name]/{R,scripts,output}`，并添加 README 和 SESSION_LOG.md。
3. **直接写代码**：无需制定计划。代码必须能运行，结果必须正确，目标必须有记录；Roxygen 文档、完整测试和完美风格则不作要求。
4. **记进度**：工作过程中，随时向 SESSION_LOG.md 追加两三行。
5. **决策点**：选择继续探索、升级为生产并达到 80/100，或附上简短说明后归档。

## 何时停手（急停开关）

随时可以停止。注明「尝试了 X，卡在 Y」后归档，再继续其他工作。停止不代表失败，探索本身就充满不确定性。
