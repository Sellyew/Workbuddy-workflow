# 探索快速通道

**用于实验性工作的轻量流程。**质量阈值：60/100（生产为 80）。不需要做计划。

## 步骤

1. **研究价值检查** —— 这会改进项目吗？如果不会，就别做。
2. **建目录** —— `mkdir -p explorations/[name]/{R,scripts,output}` + README + SESSION_LOG.md
3. **直接写代码** —— 不需要计划。必须具备：代码能跑、结果正确、目标有记录。不需要：Roxygen 文档、完整测试、完美风格。
4. **记进度** —— 做事过程中往 SESSION_LOG.md 追加两三行
5. **决策点** —— 继续探索、升级为生产（提到 80/100），或附简短说明归档

## 何时停手（急停开关）

随时都可以：停下，附注归档（「尝试了 X，卡在 Y」），然后往前走。不必有负罪感——探索本身就充满不确定性。
