# Prompt formatting core — retired (v2.6)

This file held the six-section prompt skeleton (Role / Task / Context / Constraints / Output format / Bookend) used by the `/prompt` and `/prompt-only` skills, which were retired in v2.0. It was removed in v2.6: its scaffolding (prohibition-first constraints, fixed row and sentence caps, a mandatory closing self-check) is the kind of prescription current Claude models follow too literally, and its only live pointer disagreed with the rule that replaced it.

The habit it described now lives in one short rule: [`prompt-shaping.md`](../rules/prompt-shaping.md). This stub stays so historical CHANGELOG links resolve.
